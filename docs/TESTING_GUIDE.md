# 문서 업로드 기능 테스트 가이드

## 사전 준비

### 1. 환경 변수 설정
`.env.local` 파일 확인:
```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_anon_key
SUPABASE_SERVICE_ROLE_KEY=your_service_role_key
OPENAI_API_KEY=your_openai_api_key
OPENROUTER_API_KEY=your_openrouter_api_key
NEXT_PUBLIC_APP_URL=http://localhost:3000
```

### 2. Supabase 데이터베이스 설정
1. Supabase 대시보드 접속
2. SQL Editor로 이동
3. `docs/supabase-documents-schema.sql` 파일 내용 복사
4. 쿼리 실행

### 3. 개발 서버 실행
```bash
npm run dev
```

## 테스트 시나리오

### 시나리오 1: 파일 업로드 (PDF)

**목적**: PDF 파일 업로드 및 임베딩 생성 테스트

**단계**:
1. 브라우저에서 `http://localhost:3000/dashboard` 접속
2. 로그인 (테스트 계정 필요)
3. 챗봇 생성 또는 기존 챗봇 선택
4. `/dashboard/chatbots/[챗봇ID]/documents` 접속
5. "파일 업로드" 탭 선택
6. 테스트 PDF 파일 선택 또는 드래그 앤 드롭
7. 업로드 진행 상황 확인

**예상 결과**:
- 파일 업로드 성공 메시지 표시
- 문서 목록에 새 문서 추가
- 상태: "처리 중" → "완료"
- 청크 수 표시

**테스트 파일**:
- 작은 PDF (1-2 페이지)
- 중간 PDF (10-20 페이지)
- 텍스트가 많은 PDF

### 시나리오 2: URL 크롤링

**목적**: 웹페이지 크롤링 테스트

**단계**:
1. 문서 페이지 접속
2. "URL 크롤링" 탭 선택
3. 테스트 URL 입력 (예: https://example.com)
4. "URL 추가" 버튼 클릭
5. 처리 상황 확인

**예상 결과**:
- URL 크롤링 성공
- 페이지 제목이 문서 제목으로 설정
- 콘텐츠 추출 및 임베딩 생성

**테스트 URL**:
- 간단한 웹페이지 (Wikipedia 등)
- 블로그 포스트
- 제품 페이지

### 시나리오 3: 텍스트 직접 입력

**목적**: 텍스트 입력 기능 테스트

**단계**:
1. 문서 페이지 접속
2. "텍스트 입력" 탭 선택
3. 제목 입력 (예: "테스트 문서")
4. 텍스트 내용 입력 (500자 이상 권장)
5. "텍스트 추가" 버튼 클릭

**예상 결과**:
- 텍스트 저장 성공
- 임베딩 생성
- 문서 목록에 추가

**테스트 텍스트**:
```
회사 소개

우리 회사는 2020년에 설립된 AI 기반 솔루션 제공 업체입니다. 
주요 서비스로는 챗봇 개발, 자연어 처리, 데이터 분석 등이 있습니다.

제품 및 서비스
1. AI 챗봇: 고객 지원 자동화
2. 데이터 분석: 비즈니스 인사이트 제공
3. 자연어 처리: 텍스트 분석 및 이해

연락처
- 이메일: contact@example.com
- 전화: 02-1234-5678
- 주소: 서울시 강남구
```

### 시나리오 4: 문서 검색

**목적**: 문서 검색 기능 테스트

**단계**:
1. 여러 문서 업로드 (최소 3개)
2. 검색 입력란에 키워드 입력
3. 검색 결과 확인

**예상 결과**:
- 제목에 키워드가 포함된 문서만 표시
- 대소문자 구분 없이 검색
- 실시간 필터링

### 시나리오 5: 문서 삭제

**목적**: 문서 삭제 기능 테스트

**단계**:
1. 문서 목록에서 삭제할 문서 선택
2. 삭제 버튼 (휴지통 아이콘) 클릭
3. 확인 대화상자에서 "확인" 클릭

**예상 결과**:
- 문서 삭제 성공
- 문서 목록에서 제거
- 관련 청크도 함께 삭제

### 시나리오 6: 에러 처리

**목적**: 에러 상황 처리 테스트

**테스트 케이스**:

#### 6.1 파일 크기 초과
- 10MB 이상의 파일 업로드 시도
- 예상: "파일 크기는 10MB 이하여야 합니다" 에러 메시지

#### 6.2 지원하지 않는 파일 형식
- JPG, PNG 등 이미지 파일 업로드
- 예상: "PDF, DOCX, TXT 파일만 지원합니다" 에러 메시지

#### 6.3 잘못된 URL
- 존재하지 않는 URL 입력
- 예상: "URL 크롤링에 실패했습니다" 에러 메시지

#### 6.4 빈 텍스트
- 제목만 입력하고 내용 없이 추가
- 예상: "제목과 내용을 모두 입력해주세요" 에러 메시지

### 시나리오 7: 드래그 앤 드롭

**목적**: 드래그 앤 드롭 기능 테스트

**단계**:
1. 파일 탐색기에서 PDF/DOCX/TXT 파일 선택
2. 파일을 업로드 영역으로 드래그
3. 드롭하여 업로드

**예상 결과**:
- 드래그 시 업로드 영역 하이라이트
- 드롭 시 파일 업로드 시작
- 일반 업로드와 동일한 처리

### 벡터 검색 확인
Supabase SQL Editor에서:
```sql
-- 임베딩이 제대로 저장되었는지 확인
SELECT 
  id, 
  document_id, 
  chatbot_id, 
  content,
  chunk_index,
  array_length(embedding, 1) as embedding_dimension
FROM document_chunks
WHERE chatbot_id = 'your-chatbot-id'
ORDER BY created_at DESC
LIMIT 10;

-- 벡터 검색 테스트
SELECT * FROM match_document_chunks(
  query_embedding := (
    SELECT embedding 
    FROM document_chunks 
    LIMIT 1
  ),
  match_threshold := 0.5,
  match_count := 5,
  p_chatbot_id := 'your-chatbot-id'
);
```

## 주의사항

1. **OpenAI API 비용**: 임베딩 생성 시 API 비용 발생
2. **Supabase 용량**: 많은 문서 업로드 시 스토리지 사용량 증가
3. **처리 시간**: 큰 파일은 처리 시간이 오래 걸릴 수 있음
4. **브라우저 호환성**: Chrome, Firefox, Safari 최신 버전 권장

## 문제 해결

### 임베딩 생성 실패
1. OpenAI API 키 확인
2. API 할당량 확인
3. 네트워크 연결 확인
4. 서버 로그 확인

1. 파일 크기 확인 (10MB 이하)
2. 파일 형식 확인 (PDF, DOCX, TXT)
3. 브라우저 콘솔 에러 확인
4. 네트워크 탭 확인

### 문서 목록이 비어있음
1. Supabase 연결 확인
2. chatbot_id 확인
3. RLS 정책 확인
4. 데이터베이스 테이블 존재 확인
